01 / 파일 선택

어떤 양식도, 확인 후 반영

엑셀·CSV는 열을 직접 연결하고, PDF는 읽힌 내용을 검토합니다. 미리보기에서 고친 뒤 저장하세요.

지원 범위

엑셀은 선택한 시트의 표를 읽습니다. PDF는 글자가 있는 원본만 지원하며 스캔·사진·복잡한 표는 자동 인식이 어려울 수 있습니다. PDF에서 추출한 행은 모두 수동 확인이 필요합니다. 파일 해석 모듈을 처음 불러올 때 인터넷이 필요합니다.

02 / 입력 기준

중복·분류를 먼저 확인하세요

  • 급여는 세전 총액을 사용하고, 급여에서 뺀 공제액을 다시 비용으로 더하지 않습니다.
  • 매입 합계와 개별 매입 행을 동시에 선택하지 않습니다.
  • 월세·관리비 총액과 세부 항목도 한 방식만 선택합니다.
  • 계좌 이체·대출 원금·보증금 등은 ‘손익 제외’로 기록할 수 있습니다.
  • 추정·확인 대기 금액도 손익에 포함되며 잠정으로 표시됩니다.

매출 · 비용 항목

항목 이름·분류·변동비 여부를 바꿀 수 있습니다. 사용 중인 항목은 삭제 대신 보관해 과거 기록을 유지합니다.

매월 반복되는 비용

임대료·기장료·구독료 등을 등록하세요. 매월 직접 ‘반영’을 눌러야 적용되며 같은 반복 항목은 월에 한 번만 반영합니다.

카드 · 플랫폼 수수료 추정

카드 요율은 매장 정보에서, 배달앱·플랫폼 수수료율은 위 매출 항목의 ‘수정’에서 입력합니다. 실제 계약 요율은 매장마다 다르므로 기본값을 넣지 않았습니다. 카드 수수료는 수수료율이 설정되지 않은 매출(홀·매장 결제)만 기본 대상으로 잡아 플랫폼 정산분과 겹치지 않게 했습니다. 직접 입력한 수수료와 중복 반영하지 마세요.
